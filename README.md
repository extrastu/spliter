# Spliter (React + Tailwind CSS)

纯前端全景无缝三联切图工具 — 一键将宽幅全景大片均分为 3 等份无缝连图切片，轻松制作连贯如画卷般展开的三联图。

## 功能特性

- **纯前端极速切割**：零上传、完全免费、隐私安全，通过 HTML5 Canvas 在本地进行三等分图片裁切，原图画质无损导出。
- **制作无缝三联图**：专为全景大片、风光摄影、电影截图或画卷连图设计，左右衔接严丝合缝。
- **移动端 H5 深度优化**：
  - 适配各种小屏尺寸与横竖屏，设置安全区边距（`viewport-fit=cover` 与 `env(safe-area-inset)`）。
  - 弹性按钮高度与点击反馈动画（`active:scale-95`），消除移动端高亮灰块。
  - 上传区域与预览卡片在触屏端拥有更紧凑舒适的内边距。
- **全输入场景支持**：支持文件选择、拖拽放置，以及系统剪贴板直接粘贴（`Ctrl+V` / `⌘V`）。
- **首页光刃切图动画**：复刻炫酷的 `@keyframes blade` 切割线发光动画与平滑过渡。
- **高仿真连图效果预览**：实时预览三联图拼接效果与互动展示，支持单张切片独立下载与一键打包下载全部 3 张切片。
- **深色 / 浅色模式**：持久化保存主题偏好，首屏自动匹配系统设置。

## 运行与开发

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发调试服务器（支持热重载 HMR 与小红书 API 模拟）
npm run dev

# 3. 本地预览生产构建产物
npm run build
npm run preview

# 4. 构建并打包小红书小工具规范离线 Zip 包（输出 minitool.zip）
npm run pack
```
