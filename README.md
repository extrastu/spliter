# Spliter (React + Tailwind CSS)

纯前端极速全景三联切图工具 — 一键将横幅全景图均分为 3 等份切片，在 X (Twitter) 等社交平台发布无缝连贯的三联图。

## 功能特性

- **纯前端极速切割**：零上传、完全免费、隐私安全，通过 HTML5 Canvas 在浏览器本地进行三等分图片裁切。
- **全中文本地化**：全站文案、操作提示、异常反馈均已完成地道中文化。
- **移动端 H5 深度优化**：
  - 适配各种小屏尺寸与横竖屏，设置安全区边距（`viewport-fit=cover` 与 `env(safe-area-inset)`）。
  - 弹性按钮高度与点击反馈动画（`active:scale-95`），消除移动端高亮灰块。
  - 上传区域与预览卡片在触屏端拥有更紧凑舒适的内边距。
- **全输入场景支持**：支持文件选择、拖拽放置，以及系统剪贴板直接粘贴（`Ctrl+V` / `⌘V`）。
- **首页光刃切图动画**：复刻炫酷的 `@keyframes blade` 切割线发光动画与平滑过渡。
- **高仿真 X 动态信息流预览**：实时预览发布在社交平台的无缝全景效果，支持单张独立下载与一键打包下载全部 3 张切片。
- **深色 / 浅色模式**：持久化保存主题偏好，首屏自动匹配系统设置。

## 运行与开发

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产打包
npm run build

# 4. 预览生产环境
npm run preview
```
